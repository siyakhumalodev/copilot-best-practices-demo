# claimsdesk-api

The ClaimsDesk API from the GitHub Copilot best-practices demo, split into its own repository to show working across a
frontend and a backend repository. The web app is in **claimsdesk-web**; open `../claimsdesk.code-workspace` to work on both.

`dotnet test -nologo -v q` · `dotnet run --project src/ClaimsDesk.Api`

Fictional company, synthetic data, simplified rules for demonstration only.
