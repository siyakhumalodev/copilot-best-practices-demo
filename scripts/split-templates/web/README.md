# claimsdesk-web

The ClaimsDesk web app from the GitHub Copilot best-practices demo, split into its own repository to show working across a
frontend and a backend repository. The API is in **claimsdesk-api**; open `../claimsdesk.code-workspace` to work on both.

`npm install` · `npm run dev` · `npm test`

Fictional company, synthetic data, simplified rules for demonstration only.
