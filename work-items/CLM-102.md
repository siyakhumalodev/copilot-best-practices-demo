# CLM-102 - Show how long each open claim has been open

**As a** claims team leader **I want** to see how long each open claim has been open **so that** I can chase claims before
they breach our service level.

## Acceptance criteria

- **AC1** The claims list API (`GET /api/claims`) returns `daysOpen` for each open claim (Submitted, InReview, Approved) and
  `null` for closed claims.
- **AC2** The claims list screen shows a "Days open" column.
- **AC3** Claims open for more than 30 days are marked as overdue, and the marking does not rely on colour alone.

## Notes

- Touches both the API and the web app - in the two-repository set-up these live in different repositories.
- Business rules: claims rulebook (the `claims-rules` skill).
